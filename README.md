## About
Understand how to work in a programming environment using the Command Line, Git and GitHub.


## Learning Objectives

*You will be able to:*

- Navigate computers using the command line.
- Produce new files and folders using the command line.
- Edit Python programs using both text editors and Jupyter Notebooks.
- Implement version control using Git.
- Fork and clone repositories (repos) in GitHub.

## Prerequisites
**Before this lesson(s), you should already have the appropriate installations for your system**:

- For Mac:
    - Homebrew
    - Git
    - Slack
    - Any text editor (e.g. VS Code)
    - Juypter Notebooks
